# MemoCards — карточки с интервальным повторением для Telegram

Telegram Mini App по мотивам MemoDremo: колоды (проекты) по темам, карточки «вопрос — ответ»
с изображениями и интервальное повторение по алгоритму SM‑2 (как в Anki).

```
memo-telegram/
├── apps/
│   ├── mini-app/          # Angular 17 — Telegram Mini App (вкладки Тренировка / Колоды / Библиотека / Ещё)
│   └── bot/               # Node.js + grammY — бот, открывающий Mini App
└── libs/shared/
    ├── spaced-repetition/ # чистый TypeScript: планировщик SM‑2 + unit-тесты
    └── telegram/          # Angular-сервис-обёртка над Telegram WebApp SDK
```

## Возможности

Функции и дизайн повторяют Mac-версию (MemoDremo): тёплая палитра (крем / оранжевый акцент /
тёмно-синие кнопки), тёмная тема, те же режимы и экраны.

- **Тренировка** — главный экран. Сверху аватар (переход в «Ещё»), выбор области
  (Drilling list — все активные колоды — или одна колода) и кнопка «+» (карточка / колода /
  из библиотеки). Два режима:
  - **Dremo** — проверка: стопка карточек с переворотом, четыре оценки (Забыл / Трудно /
    Помню / Легко) с подписью, через сколько карточка вернётся, свайпы со штампами «ЕСТЬ»
    (вправо) и «ЕЩЁ РАЗ» (влево), прогресс «N из M», ожидание карточек в заучивании
    с обратным отсчётом и «Показать сейчас», финальный экран с итогами по оценкам,
    «Повторить все карточки» (учить наперёд), меню «…» у карточки (озвучить, изменить,
    открыть колоду, сбросить прогресс, удалить).
  - **Memo** — запоминание: обе стороны видны сразу, без оценок, листание стрелками/свайпом.
  - **Drilling list** — шторка со списком карточек «Сегодня / Все», состоянием каждой
    (Новая / Учится / К повторению / Через N дн) и озвучкой.
- **Озвучка** — Web Speech API: язык определяется по тексту (кириллица, латиница с
  диакритикой, CJK и т. д.), динамик на карточке и в списках, автоозвучивание при перевороте,
  скорость речи — в настройках.
- **Колоды** — несколько проектов с похожими темами; у каждой эмодзи (сетка быстрого выбора
  или свой символ), описание, тумблер «В Drilling list», «молния» для тренировки только
  этой колоды, бейджи новых / к повторению / выученных. В деталях — Тренировать / Memo /
  Карточка, поиск по карточкам, меню со сбросом прогресса всех карточек.
- **Карточки** — вопрос (лицевая сторона), ответ (обратная), необязательное изображение:
  из файла/камеры или из буфера обмена (кнопка «Буфер» и ⌘V). Настройка «Только картинка на
  лицевой стороне» — вопрос показывается после переворота. Кнопки «Сохранить и ещё»
  и «Озвучить вопрос». Картинка ужимается до 1280 px и хранится локально с превью 160 px.
- **Интервальное повторение** — SM‑2: шаги заучивания 1 и 10 минут, выпуск на 1 день,
  «Легко» — 4 дня, далее интервал × ease‑factor (2.5 по умолчанию, минимум 1.3),
  при ошибке интервал делится пополам. Лимит новых карточек в день настраивается.
- **Библиотека** — готовые колоды (`apps/mini-app/src/assets/library`), добавляются копией
  в «Колоды»; у добавленных — «Открыть» и «Ещё раз» (повторная копия).
- **Ещё** — профиль с инициалами и серией дней, плитки статистики (серия, повторений сегодня,
  к повторению, выучено / всего), график активности за 14 дней, кривая забывания и график
  интервального повторения (SVG), настройки (новых карточек в день, свайпы, картинка на лицевой
  стороне, автоозвучка, скорость речи, имя), резервные копии: Telegram CloudStorage (без
  изображений, доступна на всех устройствах) и экспорт/импорт JSON (полная копия с
  изображениями, формат совместим с Mac-версией).
- Интеграция с Telegram: светлая/тёмная схема по `colorScheme`, кнопка «Назад», haptic
  feedback, отключение закрытия приложения вертикальным свайпом, CloudStorage. Вне Telegram
  всё работает в обычном браузере (с fallback на `localStorage` / `window.confirm`), что
  удобно для разработки.

## Где хранятся данные

Все данные (колоды, карточки, изображения, журнал ответов) лежат в **IndexedDB устройства**
внутри WebView Telegram. Бэкенда нет. Чтобы не потерять прогресс при смене устройства или
очистке кэша, используйте «Ещё → Резервные копии».

## Требования

- Node.js 20 LTS

## Команды

```bash
yarn install

# мини-приложение
npx nx serve mini-app            # http://localhost:4200
npx nx build mini-app            # production-сборка → dist/apps/mini-app/browser

# бот
npx nx build bot                 # → dist/apps/bot/main.js (самодостаточный бандл)

# качество
npx nx run-many -t lint
npx nx run-many -t test
```

## Запуск в Telegram

### 1. Создайте бота

В [@BotFather](https://t.me/BotFather): `/newbot` → сохраните токен.

### 2. Опубликуйте мини-приложение по HTTPS

Telegram открывает Mini App только по HTTPS. Подойдёт любой статический хостинг:
GitHub Pages, Vercel, Netlify, Cloudflare Pages, собственный nginx.

```bash
npx nx build mini-app
# если приложение будет лежать не в корне домена, укажите base href:
npx nx build mini-app --base-href /memo/
```

Загрузите содержимое `dist/apps/mini-app/browser` на хостинг. Роутинг в приложении
hash‑based (`/#/decks`), поэтому fallback на `index.html` настраивать не нужно.

Пуш в `main` запускает `.github/workflows/deploy.yml`: lint и тесты, затем миграции
и Edge Functions в Supabase (если задана переменная `SUPABASE_PROJECT_REF`) и выкладку
на GitHub Pages по адресу `https://<user>.github.io/<repo>/`. Секреты Actions:
`SUPABASE_ACCESS_TOKEN`, `SUPABASE_DB_PASSWORD`, `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_WEBHOOK_SECRET`. Переменные: `SUPABASE_PROJECT_REF`, `WEB_APP_URL`.
Публичный URL и publishable key лежат в `apps/mini-app/src/environments/environment.ts`.
После первого деплоя функций вебхук бота ставится так:

```bash
SUPABASE_URL=https://<ref>.supabase.co node --env-file=supabase/functions/.env tools/telegram-setup.mjs
```

Для локальной проверки прямо в Telegram можно пробросить dev-сервер через туннель
(например, `ngrok http 4200` или `cloudflared tunnel --url http://localhost:4200`) и
использовать выданный HTTPS‑адрес.

### 3. Запустите бота

```bash
cp apps/bot/.env.example apps/bot/.env   # заполните BOT_TOKEN и WEB_APP_URL
npx nx build bot
node --env-file=apps/bot/.env dist/apps/bot/main.js
```

При старте бот сам регистрирует команды и кнопку меню (Menu Button) с Mini App.
Команда `/start` присылает inline‑кнопку «Открыть карточки».

Дополнительно можно создать прямую ссылку вида `t.me/<bot>/<app>` через `/newapp` в
BotFather, указав тот же `WEB_APP_URL`.

Бота можно разместить на любом сервере с Node.js 20 (systemd, Docker, PM2) — он работает
через long polling, входящие порты не нужны.

## Как добавить колоду в библиотеку

1. Положите JSON в `apps/mini-app/src/assets/library/<id>.json`:

   ```json
   {
     "id": "my-deck",
     "title": "Название",
     "description": "Описание",
     "emoji": "📚",
     "language": "RU",
     "cards": [
       { "question": "Вопрос", "answer": "Ответ", "imageUrl": "images/optional.jpg" }
     ]
   }
   ```

   `imageUrl` необязателен и указывается относительно папки `assets/library`.
2. Добавьте запись в `index.json` (`id`, `title`, `description`, `emoji`, `language`,
   `cardCount`, `file`).

## Архитектура мини-приложения

- `core/models/interfaces.ts` — доменные типы (Deck, Card, StoredImage, ReviewLogEntry …).
- `core/db` — IndexedDB через `idb` (`AppDatabase`, `MemoRepository`).
- `core/store/memo-store.service.ts` — состояние на сигналах; каждая мутация сначала пишется
  в базу, затем обновляет сигналы.
- `core/study/study.service.ts` — формирование очереди на сегодня, описание состояния
  карточки и применение оценок через планировщик из `@memo/shared/spaced-repetition`.
- `core/study/study-session.service.ts` — состояние тренировки на сигналах (область, режим
  Memo/Dremo, очередь, прогресс «N из M», итоги); живёт на уровне приложения, поэтому
  переключение вкладок не сбрасывает сессию.
- `core/speech` — озвучка (Web Speech API) и определение языка по тексту.
- `core/stats` — статистика, активность за 14 дней и кривые забывания (`retention.ts`).
- `core/images`, `core/library`, `core/backup`, `core/profile`, `core/toast` — сервисы.
- `ui/` — переиспользуемые компоненты (иконки, таб‑бар, шапка, карточка тренировки,
  bottom sheet, action sheet, аватар, бейдж состояния, тосты …).
- `features/` — экраны: `drilling` (тренировка, сессия Dremo, Memo, шторка Drilling list),
  `decks`, `cards`, `library`, `more` (графики в `retention-charts` и `activity-chart`).

Все компоненты standalone с `OnPush`, состояние на сигналах, операции с данными иммутабельные.
